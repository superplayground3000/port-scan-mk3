# 4.0.0 Release Notes — Smaller Go Interfaces

## Summary

Version 4.0.0 replaces the shared configuration object with workflow-specific
values. It also moves HTTP and OAuth pressure adapters to `pkg/pressure`.

The command-line interface does not change. Commands, accepted flags, default
values, output schemas, exit classes, and snapshot formats stay compatible.
This release changes the public Go API for library callers.

## Breaking Go API changes

- Use `config.ParsePrePing`, `config.ParseGenerateBuckets`, `config.ParseScan`,
  or `config.ParseValidate` for command arguments.
- Use `config.NewPrePing`, `config.NewGenerateBuckets`, `config.NewScan`, or
  `config.NewValidate` for values from another source.
- Pass each opaque configuration to its matching workflow. The workflow owns
  the narrow configuration interface.
- `scanapp.RunOptions` now exposes `Dial`, `PressureLimit`,
  `DisableKeyboard`, `PressureSource`, `ProgressInterval`, and
  `ReachabilityChecker`.
- `RunOptions.PressureSource` replaces the old pressure fetcher and HTTP-client
  fields.
- `config.Config`, `config.Parse`, and `config.ParseFor` are removed.
- `scanapp.ScanRecord` and the public writer adapters are removed. Runtime code
  uses `writer.Record` directly.
- The old pressure fetcher types and constructors are removed. Use
  `pressure.NewSimpleHTTP` or `pressure.NewOAuthMulti` for a custom pressure
  source.

## Migration examples

Replace shared argument parsing with the parser for the selected workflow:

```go
cfg, err := config.ParseScan(args)
if err != nil {
    return err
}
return scanapp.Run(ctx, cfg, stdout, stderr, scanapp.RunOptions{})
```

For non-CLI scan values, construct a validated pressure policy first:

```go
policy, err := config.SimplePressure("https://router.example/pressure", 5*time.Second)
if err != nil {
    return err
}

cfg, err := config.NewScan(config.ScanValues{
    CIDRFile:       "targets.csv",
    CIDRIPCol:      "ip",
    CIDRIPCidrCol:  "ip_cidr",
    ResumeInput:    "buckets.json",
    Output:         "out",
    Workers:        10,
    DialTimeout:    100 * time.Millisecond,
    DispatchDelay:  10 * time.Millisecond,
    BucketRate:     100,
    BucketCapacity: 100,
    LogLevel:       "info",
    Format:         "human",
    Pressure:       policy,
})
if err != nil {
    return err
}
return scanapp.Run(ctx, cfg, stdout, stderr, scanapp.RunOptions{})
```

For an injected pressure source, implement the consumer-owned interface:

```go
type source interface {
    Sample(context.Context) (pressure.Sample, error)
}

opts := scanapp.RunOptions{PressureSource: mySource}
```

The explicit local `source` declaration is optional. A value with the same
`Sample` method satisfies `scanapp.PressureSource`.

## Compatibility

- Existing CLI invocations do not need migration.
- Current and legacy snapshots remain readable.
- The CSV and unreachable-result schemas do not change.
- `validate` still accepts and verifies the complete legacy flag set.

## Rollback and mitigation

Version 3.0.1 remains suitable for CLI rollback because the CLI, CSV, and
snapshot contracts are unchanged. A Go application that rolls back must also
restore its old `config.Config` and pressure-fetcher calls.

If an application cannot migrate in one change, isolate its version-specific
calls behind a small application-owned adapter. Do not pass partially verified
values to a workflow.
